RAMBLA Premontato - installer locale

1. Apri PowerShell nella cartella di questo progetto.
2. Esegui: powershell -ExecutionPolicy Bypass -File .\install\Install-Premontato.ps1
3. Se richiesto, scegli WorkflowIntegration.node dalla cartella di Resolve.
4. In Resolve apri Workspace > Workflow Integrations > RAMBLA Premontato.

Il file SDK ufficiale non viene distribuito. Il progetto e le clip restano locali.
Per creare un EXE firmato serve il packaging Windows (IExpress/PS2EXE) e la firma digitale.
