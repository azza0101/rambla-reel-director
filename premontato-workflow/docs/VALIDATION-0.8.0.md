# Premontato 0.8.0 — salvataggi e aggiornamento

Costruito: salvataggi .premontato.json versionati e atomici; autosave/recupero, legame al file con nome in metadati locali separati, bozze UI, controlli di modifica/disponibilità dei media, protezione del file modificato esternamente. Comandi Apri/Salva/Salva con nome. SaveProject SDK con controllo identità e fallimento esplicito. Download a chunk con byte effettivi, verifica SHA-256, progressi di estrazione/installazione inviati tramite pipe casuale dal processo PowerShell anche elevato. Riavvio Electron solo dopo salvataggi e installazione riuscita, con argomenti originali. Nessun riavvio di Resolve.

Verificato: test unitari su roundtrip, file malformati, sostituzione disco fallita, recupero dei progetti senza media, impronte riprese, cambiamenti esterni, normalizzazione degli array richiesti dal renderer, mancato salvataggio Resolve, avanzamento download, hash, progress pipe informativa e ordine cleanup/relaunch. Revisione indipendente: riprodotti e corretti dati persistiti non validati e array opzionali che interrompevano la riapertura. Escape dei campi interpolati e CSP senza script inline.

Test con analisi reale delle tre clip: salvato e riaperto file di 1849243 byte, 12 battute e 33 intervalli visivi, testo italiano integro e file con nome ripristinato. Renderer reale in browser con Session/worker e filesystem: salvataggio/riapertura, bozza numerica conservata, conferma revisione non distrugge i campi, blocco per valori non applicati, progressi aggiornamento, 66 still e nessun errore JavaScript a 1100/680px. Pipe provata con processo PowerShell reale (fixture senza installazione).

Rilancio reale usando l’Electron fornito da Resolve: primo PID 3192, nuovo PID 103100, finestra riaperta, argomenti e progetto con nome recuperati. Questo è un banco di prova esterno: l’SDK non inizializza da quel contesto, quindi la riconnessione al bridge dopo un rilancio avviato dal pannello Resolve e l’installazione completa con UAC non sono state collaudate end-to-end. Non dichiararle verificate. La prima installazione da 0.7.0 usa ancora il vecchio updater e richiede una riapertura manuale; le nuove funzioni di riavvio operano dagli aggiornamenti successivi.
