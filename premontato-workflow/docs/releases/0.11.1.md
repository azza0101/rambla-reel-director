# Premontato 0.11.1

Integrates the 0.11.0 staged Groq workflow with a generic role-consistency check: for a classified screenplay dialogue beat, use its scripted speaker; preserve inferred roles for actions. This prevents contradictory model labels from suppressing relevant close shots. No source-specific corrections or ranges are included.

Validated: 103 Python tests, 102 JavaScript tests; complete real-scene Session run with 12/12 dialogue beats, 18 moments, two actions and one listener reaction. Warm analysis 2.346 s with zero Groq requests. The installed UI update and timeline creation are verified separately after publication.
