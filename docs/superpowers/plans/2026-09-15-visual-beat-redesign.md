# Visual-beat Director redesign (user-authorized quality gate)

1. Replace production per-chunk generation with one narrative pass and bounded batches of BROLL beats. Narrative sees compact transcript; shot batches see only each beat's covered speech and source-quoted anchors, global prohibitions and recent concept memory.
2. Exact, ordered, contiguous chunk coverage; BROLL / KEEP_TALKING_HEAD / CONTINUE_PREVIOUS_VISUAL; continuation must reference an earlier active visual. Scope is explicit: quality gate covers first eight chunks only. Full production input informs theme and prohibitions, never retrieval nouns. A scoped gate physically excludes out-of-scope chunks from all prompts; the first eight form its entire input.
3. Every shot references an affirmed or neutral-question anchor in its own beat, activates no earlier than that anchor, and cannot add vocabulary outside its grounded scene. Negated concepts cannot be shown; unanswered questions cannot become adverse factual claims. Default one shot; up to three only with a quoted explicit sequence. These structural/lexical checks are bounded safeguards, not a proof of semantic entailment across languages: actual output requires user review.
4. Batch generator may reject unsupported BROLL as KEEP. Repetition overlap is penalized before sourcing, preserving intentional continuity and otherwise suppressing repeated visuals without inventing replacements.
5. Retain exact prompts/raw responses, token counts, wall times, load time and accepted/rejected call records. Bound JSON repair to one retry. Version cache by prompts, schema, scope, batch size and source.
6. Tests: scope leakage, missing/duplicate coverage, false claims and negation, multi-shot bounds, recent repetition, no provider calls for KEEP/CONTINUE, cache and batching. Run real local Qwen only on the approved first-eight gate; no ASR, provider searches, installs or further generation after the gate. No publication until quality review.
