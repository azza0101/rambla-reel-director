# Approval — Online Sourcing Engine V1

Date: 2026-09-12

The user explicitly approved the new product direction and asked ChatGPT to continue implementation work directly through GitHub after Codex credits were exhausted.

Approved direction:

- prioritize a fast, reliable backend engine before Resolve GUI polish;
- make online B-roll sourcing the normal path rather than requiring a pre-existing local library;
- use Pexels first, then Pixabay and Coverr, with YouTube/Instagram later behind source-rights and platform constraints;
- keep Qwen3-VL-Embedding-2B as the visual semantic ranking stage;
- use local cache/library as reuse generated by prior sourcing, not as a prerequisite;
- preserve provenance, source URL, attribution/rights state, candidate scores, and alternatives in the Edit Plan/review surface;
- keep Analyze read-only with respect to Resolve and keep `REEL_MASTER` untouched;
- inspect open-source projects for useful architecture and behavior;
- source code from repositories with compatible licenses may be adapted with required notices/attribution;
- repositories without a license may be studied for behavior, interfaces, and architecture, but substantial code is independently reimplemented rather than copied verbatim.
